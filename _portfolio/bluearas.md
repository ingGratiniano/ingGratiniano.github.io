**Ingeniero de Firmware en PS.BPO - BlueAras (May 2023 - Feb 2024)**

**Problema:** Implementar el firmware para el sistema robótico de intercambio autónomo de baterías para drones (D-BEST v3.0), un sistema crítico para el monitoreo aéreo continuo.

**Mi rol:** Desarrollé el firmware sobre STM32, implementando los protocolos CAN-FD, UART y SPI para la integración con SBCs. Realicé pruebas funcionales y validación de las tarjetas electrónicas del sistema.

**Tecnologías:** STM32, CAN-FD, UART, SPI, SBCs.

**Logros:** Sistema de intercambio de baterías funcional y confiable para misiones de monitoreo.
